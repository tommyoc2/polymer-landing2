Today, we're excited to announce that Polymer is integrating with Lucid, the no-code platform and SDK that simplifies multi-chain operations for applications. Lucid users can leverage Polymer's Prove API alongside seven other bridges within Lucid's platform. This collaboration creates two significant advantages:

**Accelerated Chain Expansion for Lucid**

The Prove API integration directly into Lucid's backend drastically simplifies their chain expansion process. On the contract side, using the Prove API requires just a single method addition. This integration allows Lucid to:

- Deploy to new chains with significantly reduced development time
- Scale their multi-chain support without proportional engineering overhead
- Maintain consistent security standards across all supported ETH L2s

**Superior Performance with Maintained Security**

Polymer will be integrated in Lucid V2, where we expect to rank the highest on Lucid's system for both speed and cost-effectiveness while maintaining robust security. With this integration, users will benefit from:

- **Cost efficiency**: Reduced gas fees by eliminating additional contract deployments
- **Extensibility**: Support across various rollup ecosystems including Optimism's Superchain and Arbitrum rollups
- **Faster speeds**: Relay state information between rollups in ~3-4 seconds with proofs
- **Developer-friendly implementation**: Simplified 3-step process (emit event, request proof, validate action)
- **xERC20 support: **Lucid’s asset controllers make Polymer asset-transfer compatible, letting users bridge xERC20 tokens with ease.

‍

### **How Polymer Works Within Lucid**

Polymer can be utilized in two ways on Lucid:

1. **As a standalone bridge option**: Users can route xERC20 transactions through Polymer directly by choosing Polymer as their bridge of choice
2. **Within the Multi-Bridge consensus module**: Organizations can configure a 2-out-of-3 bridge consensus requirement, where Polymer serves as one of the validators before executing transactions on destination chains

**What This Means for Lucid Users**

Whether you're managing a DAO treasury across multiple chains or coordinating governance decisions that span several ecosystems – Polymer makes any and all cross-chain actions feel like they're happening on a single chain. 

This solution offers the best option for both communities and foundations, providing fast, cheap, and safe transfers across all EVM rollups.

- **Enhanced security options**: Add Polymer to your Multi-Bridge consensus setup for an additional layer of verification
- **Faster cross-chain operations**: Leverage Polymer's industry-leading settlement (~3-4 seconds) for time-sensitive treasury or governance actions
- **Reduced transaction costs**: Benefit from Polymer's proof-based model that minimizes gas consumption
- **Streamlined asset transfers**: Use the same familiar Lucid interface while gaining access to Polymer's optimized interop capabilities

Polymer’s mission is to free developers from the shackles of having to build on opaque, restrictive interop systems which are not built for scale, so that they can focus on building better and more useful applications. 

Cross-chain applications are leveraging the Prove API to build hyper-performant applications that have zero interop bottlenecks. Come join their ranks.
